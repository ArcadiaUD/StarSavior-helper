# 旅程助手（StarSavior-helper）

Star Savior 简体中文 PC 版旅程（跑马）辅助面板

</div>

游戏里只告诉你选项写的是什么，不告诉你这个选项要付出什么、成功能拿多少。
旅程助手把这部分直接摆在屏幕上：选项的消耗、成败收益、当前数值、训练收益、状态折扣，边跑边看。

面板贴在屏幕侧边、置顶显示，用画面识别认出当前事件，**只读屏幕画面**：
不修改游戏文件、不注入游戏进程、不代替你点击或按键。

## ⚠️ 使用前须知

旅程助手是第三方辅助工具：

- 并非 Star Savior 官方产品，与游戏开发方、发行方没有任何关系。
- 只截取游戏窗口画面做文字识别，不修改游戏文件、不注入游戏进程、不模拟点击与按键。
- 识别依赖**简体中文**游戏界面；繁体、英文界面下提示会失准。
- 面板显示的数据来自游戏本体的本地解包文件，可能和游戏内实际数值有落差，请以游戏内显示为准。
- 程序未做数字签名，首次运行 Windows 可能提示「未知的发布者」；杀毒软件也可能对打包程序误报。

识别与查询可能因以下情况失准或失效：

- 游戏版本更新（界面、图标、文字都可能改）
- 游戏界面语言不是简体中文
- 画面分辨率或窗口比例改变
- 游戏窗口被其他窗口完全遮住、或缩到最小
- Windows 环境差异（高 DPI 缩放、多屏幕）
- 杀毒软件或其他程序干扰

使用第三方辅助工具可能存在账号与使用风险，请自行评估后使用。

## 🚀 下载与开始

### 下载

**下载页：[GitHub Releases](https://github.com/ArcadiaUD/StarSavior-helper/releases)。一般用户请下载完整程序包。**

| 文件 | 用途 |
| --- | --- |
| `StarSavior-helper-V1.0.zip` | 完整程序包。含面板本体、Python 运行环境、识别模型、全部数据与图片素材。**不需要另外安装 Python、不需要自己解包游戏**，解压即用。 |
| `SHA256SUMS.txt` | 上列压缩包的 SHA-256 校验码。 |
| `data-*.zip` | 数据包，**不用手动下载**。面板检测到数据更新时，会在面板内自行完成下载与校验。 |

全部文件与版本说明均位于 [GitHub Releases](https://github.com/ArcadiaUD/StarSavior-helper/releases)。

整包约 128 MB；数据包另计约 12 MB，只在游戏更新后才需要。

### 开始使用

1. 解压 `StarSavior-helper-V1.0.zip`，得到 `旅程助手` 文件夹。
   **整个文件夹一起用，exe 不能单独拿出来跑。** 建议解压到D 盘这类可写入的位置，不要放在 `C:\Program Files` 底下。
2. 打开 Star Savior PC 版，界面语言设为**简体中文**，用窗口模式（或至少不要让面板把游戏整个盖住）。
3. 双击 `旅程助手.exe`。面板会自动贴到屏幕右缘、置顶显示，不会抢走游戏焦点。
4. 进入旅程后，面板会实时识别当前事件：上方列出识别到的选项与收益，右下「当前选择」区显示每个选项的消耗与成败结果。

首次启动需要读取数据并加载识别模型，大约十秒后出现第一次结果。

面板本身可以拖动；它把自己盖住的那块画面从识别范围里排除掉，所以贴在游戏上也不会互相干扰。
游戏窗口被完全遮住或缩到最小时无法识别，这是屏幕截取的固有限制。

## 💻 运行环境

| 项目 | 条件或验证状态 |
| --- | --- |
| Windows 10 1803 以上 64 位 | 支持目标；界面使用系统的 WebView2 内核（Win11 内置，Win10 装过 Edge 的通常已有）。其他 Windows 环境仍待更多实测。 |
| Star Savior PC 简体中文版 | 必要条件；识别比对的是简体文字。繁体与英文界面目前不支持。 |
| 屏幕分辨率 | 建议 1920×1080 以上。面板默认 360×940 贴屏幕右缘；屏幕工作区太矮时会自动收窄。 |
| 屏幕缩放 | 100% 已实测；高 DPI 缩放下按物理像素定位，仍建议自行确认落位。 |
| 游戏窗口 | 前台或至少未被完全遮住；缩到最小时无法识别。 |
| 网络 | 只有「检查更新」与最新消息／兑换码需要。其余查询与识别完全离线可用。 |
| 权限 | 不需要管理员权限。 |

## ✨ 面板功能

### 实时识别

- 认出当前事件标题与选项，列出每个选项的**消耗**（体力／道具／金币／潜能点）与**成功、失败分别拿到什么**。
- 同名事件会标出来源，避免两张卡的同名事件混淆。
- 面板盖住的那块画面会自动排除，不会把自己的文字读进去。

### 资料库十五个栏目

按类型分四段，面板入口区与图鉴窗口的页签顺序一致：

- **角色与养成**：救援者、角色、阿尔克那、潜质、未实装
- **战斗内容**：作战首领、回廊、讨伐委托
- **道具与机制**：装备、破防技能、状态效果、称号
- **资讯与剧情**：最新消息、兑换码、活动档案

点任一栏目会打开左侧的图鉴窗口，显示该栏目的完整列表与图标。

### 其他

- **最新消息／兑换码**：启动后抓官方公告与兑换码；本机取不到时显示包内快照并标注抓取失败。
- **右上两个按钮**：「git 仓库」打开本仓库，「检查更新」手动检查数据更新。

## 🔧 疑难排解

<details>
<summary><b>识别不出来、或提示的内容不对</b></summary>

请确认：

1. 游戏界面语言是**简体中文**。
2. 游戏窗口没有被其他窗口完全遮住，也没有缩到最小。
3. 面板没有盖住事件选项那一块（面板可以拖动）。
4. 游戏正在旅程事件画面，且已经出现选项。

如果是在游戏改版后才出现，可能是界面、图标或文字变了，
请保留 `panel.log` 与当时的截图，通过 Issues 回报，等数据更新。

</details>

<details>
<summary><b>面板挡住游戏</b></summary>

面板可以拖到其他位置，也可以直接关掉；关掉不影响游戏。
识别只需要游戏窗口没有被完全遮住。

</details>

<details>
<summary><b>检查更新失败</b></summary>

面板会把失败原因写出来。最常见的原因是网络到 `github.com` 与
`raw.githubusercontent.com` 不稳定；程序会自动在直连与两个中转前缀之间切换，全部失败时先继续用旧数据，过一阵子再点「检查更新」。

如果手动检查一直失败，可以先确认这两个域名在本机能不能打开。

</details>

<details>
<summary><b>杀毒软件出现警告</b></summary>

完整版包含 Python 运行环境、识别相关套件与打包后的执行文件，
部分杀毒软件会因为打包程序或更新机制产生警告。

请先确认文件确实来自[本项目的 GitHub Releases](https://github.com/ArcadiaUD/StarSavior-helper/releases)，
并可用附带的 `SHA256SUMS.txt` 核对文件。

**不要对来源不明的文件加入杀毒排除。**

</details>

<details>
<summary><b>双击后面板起不来</b></summary>

确认解压位置**可写入**（面板启动时会在程序目录写入页面与日志）。
放在 `C:\Program Files` 底下而没有管理员权限时会启动失败，换到桌面或 D 盘即可。

另外本程序需要系统的 WebView2 内核；Win11 内置，Win10 若从来没装过 Edge，装一次微软的 WebView2 运行时即可。

</details>

<details>
<summary><b>想退回随包数据</b></summary>

删除 `%LOCALAPPDATA%\JourneyPanel\data` 目录，面板会自动回落到程序包内的数据。

</details>

## 🐛 问题回报

请使用 **[GitHub Issues](https://github.com/ArcadiaUD/StarSavior-helper/issues)**。

建议附上：

```text
旅程助手版本：
Windows 版本：
Star Savior 版本：
游戏界面语言：
屏幕分辨率与缩放：
问题栏目或事件：
问题发生时间：
是否能稳定重现：
```

并尽量提供 `panel.log` 的相关片段、异常画面截图、问题发生前后的操作步骤。

示例：

```text
旅程助手：V1.0
Windows：Windows 11 64-bit
Star Savior：目前游戏版本
界面语言：简体中文
分辨率：1920×1080，缩放 100%
问题：某个事件被识别成另一个同名事件
重现：每次都会
```

只写「不能用」「卡住了」「没反应」，通常不足以判断问题。信息越完整越容易重现与修正。

回报前请确认日志、截图或其他附件里没有 UID、账号信息、角色名称等不希望公开的内容。
