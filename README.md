# 旅程助手 · StarSavior-helper

给 PC 端《StarSavior》旅程（跑马）玩法做的辅助面板。

游戏里只告诉你选项写的是什么，不告诉你这个选项要付出什么、成功能拿多少。旅程助手把这部分**直接摆在屏幕上**：
选项的消耗、成败收益、当前数值、训练收益、状态折扣，边跑边看。面板带 OCR 识别，贴在屏幕侧边跟着游戏走。

> ⚠️ **V1.0 首个公开版本**
>
> 面板只**读屏幕画面**做识别并显示提示：不修改游戏文件、不注入游戏进程、不模拟点击与按键。
> 识别依赖游戏界面为**简体中文**；繁体／英文界面下提示会失准。

**快速链接**：[下载最新版](https://github.com/ArcadiaUD/StarSavior-helper/releases) · [数据更新说明](changelog.md) · [问题反馈](https://github.com/ArcadiaUD/StarSavior-helper/issues)

## ⚠️ 使用前须知

- 第三方辅助工具，不是游戏官方产品，与官方无任何关系。
- 只截取游戏窗口的画面做文字识别，**不会**改游戏文件、不会注入进程、不会替你点击或按键。
- 识别结果仅供参考。界面语言、分辨率、UI 改版、窗口被遮挡都会影响准确率，最终请以游戏内实际显示为准。
- 程序没有数字签名，首次运行 Windows 可能提示「未知发布者」；杀软也可能对打包程序误报（详见常见问题）。
- 使用第三方工具存在账号与使用风险，请自行评估后再用。

## 🚀 下载与使用

**下载页：[Releases](https://github.com/ArcadiaUD/StarSavior-helper/releases)** — 一般用户下载 `StarSavior-helper-V1.0.zip`。

| 文件 | 用途 |
|---|---|
| `StarSavior-helper-V1.0.zip` | 完整程序包，解压即用。已内置全部数据与图片素材：**不需要联网、不需要自己解包游戏** |
| `SHA256SUMS.txt` | 上面这个文件的 SHA-256 校验码，下载后可自行核对 |

数据包（`data-*.zip`）**不用手动下载**：面板发现数据有更新时，会在面板内自己完成下载、校验与生效。

使用步骤：

1. 解压 `StarSavior-helper-V1.0.zip`，得到 `旅程助手` 文件夹。
   **整个文件夹一起用，exe 不能单独拿出来跑。** 建议解压到桌面或 D 盘这类可写目录，别放 `C:\Program Files` 下。
2. 打开游戏，界面语言选**简体中文**，用窗口模式（或至少别让面板把游戏完全遮住）。
3. 双击 `旅程助手.exe`。面板会自动贴到屏幕右缘、置顶显示，不抢游戏焦点。
4. 进入旅程后，面板会实时识别当前事件：上方显示识别到的选项与收益，右下「当前选择」区列出每个选项的消耗与成败结果。

首次启动要读盘并加载识别模型，约十秒左右出第一次结果。

## ✨ 面板里有什么

十五个栏目，按类型分四段：

- **角色与养成**：救援者、角色、阿尔克那、潜质、未实装
- **战斗内容**：作战首领、回廊、讨伐委托
- **道具与机制**：装备、破防技能、状态效果、称号
- **资讯与剧情**：最新消息、兑换码、活动档案

点任一栏目会打开左侧的图鉴窗口，页签顺序与面板入口一致。每个栏目的条目数见下方「数据规模」。

其他：

- **实时识别**：识别当前事件标题与选项，列出每个选项的消耗（体力／道具／金币／潜能点）与成功、失败分别拿到什么；同名事件会标出来源。
- **最新消息／兑换码**：启动后抓官方公告与兑换码；本机取不到就显示包内快照并标注抓取失败。
- **两个按钮**：右上「git 仓库」打开本仓库，「检查更新」手动检查数据更新。

## 🔄 数据是怎么更新的

游戏更新后数据会变。整包 300 MB，重下一次太浪费，所以数据层可以单独更新：

- 启动后到点会自动检查一次（**六小时冷却**，手动检查不受限）。
- **自动检查失败不打扰**：静默跳过，什么都不弹。
- 「检查更新」是手动检查，失败会把原因摊开写出来——哪条线路、什么错误。
- 更新全程在面板内：下载 → 校验（整包与逐文件 sha256）→ 只写入有变化的文件 → 提示重启 → 重启后生效。
- 任何一步不通过都**保留旧数据**，不会出现更新一半坏掉的面板。
- 不想更新可以选「稍后」或「跳过此版本」，跳过的版本不会再提示。
- 数据包放在 GitHub Release，不进仓库本体。

## 💻 运行环境

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 1803 以上 64 位；界面用系统 WebView2 内核（Win11 自带，Win10 装过 Edge 的通常也有） |
| 游戏 | PC 端《StarSavior》，界面语言**简体中文** |
| 屏幕 | 建议 1920×1080 及以上；面板默认 360×940 贴屏幕右缘，屏幕太矮会收窄 |
| 网络 | 只有「检查更新／下载数据」和最新消息需要联网，纯查资料与识别离线可用 |
| 权限 | 不需要管理员权限 |

## ❓ 常见问题

**杀软报毒／SmartScreen 拦截**
程序用 PyInstaller 打包且没有签名，误报很常见。加信任或选「仍要运行」即可。想自己核对，可用 `SHA256SUMS.txt` 里的哈希校验下载到的压缩包。

**面板挡住了游戏**
面板可以拖动、也可以关掉；游戏窗口只要不是被完全遮挡，识别就照常工作。面板自己会把自己覆盖的那块画面从识别范围里排除掉。

**识别出来的东西不对／没反应**
先确认游戏界面是简体中文，再看面板是不是把事件选项那块盖住了。分辨率变化、游戏 UI 改版都可能让识别失准，这种时候等数据更新。

**更新失败**
面板会把失败原因写出来。国内网络访问 `github.com` 与 `raw.githubusercontent.com` 不稳定时容易失败，程序会自动在直连与两个中转前缀之间切换；都失败就先继续用旧数据，过一阵再点「检查更新」。

**想退回随包数据**
删掉 `%LOCALAPPDATA%\JourneyPanel\data` 目录即可，面板会自动回落到程序包内的那一份。
